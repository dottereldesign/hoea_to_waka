# Native language labels

Small, locally served Noto subsets cover only the native menu labels. They avoid expensive system-font fallback on the first opening. They are not used to replace the typeface of translated pages.

- `han.woff2`: Noto Sans SC, `普通话廣東話`
- `devanagari.woff2`: Noto Sans Devanagari, `हिन्दी`
- `gurmukhi.woff2`: Noto Sans Gurmukhi, `ਪੰਜਾਬੀ`

Source: Google Fonts CSS2 API, weight 400, `text` parameter containing the characters above, downloaded 3 November 2026. Converted to WOFF2 with FontTools; shaping tables are retained. Each font's SIL Open Font License is included alongside it. Original sources: https://github.com/google/fonts/tree/main/ofl/notosanssc, https://github.com/google/fonts/tree/main/ofl/notosansdevanagari, https://github.com/google/fonts/tree/main/ofl/notosansgurmukhi.
