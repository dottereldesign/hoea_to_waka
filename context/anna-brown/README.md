# Anna Brown / Hoea to Waka Context Pack

This folder is the working context set for rebuilding the Hoea to Waka website from scratch.

## Files

- `01-client-brief.md`  
  High-level client, audience, contact, and project notes pulled from email.

- `02-current-website-inventory.md`  
  Structured snapshot of the current live website and its existing messaging.

- `03-current-website-audit.md`  
  Problems, risks, useful carryovers, and rewrite implications based on the current site.

- `04-source-content-dump.md`  
  Place to paste raw source material from the existing site, docs, notes, or future emails.

## Intent

These files are meant to do two things:

1. Preserve what already exists so nothing important gets lost during the rebuild.
2. Give future design, copy, and development work fast context without needing to revisit the old site.
